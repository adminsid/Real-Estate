# Issue Tracker: GitHub Issues

This repository uses **GitHub Issues** for issue tracking.

## Repository
- **Remote**: `https://github.com/adminsid/Real-Estate.git`
- **CLI**: GitHub CLI (`gh`)

## Commands for Skills

### Create an issue
```bash
gh issue create --title "<Title>" --body "<Body>"
```

### List open issues
```bash
gh issue list --state open --limit 30
```

### View an issue
```bash
gh issue view <number> --comments
```

### Close an issue
```bash
gh issue close <number>
```

## Conventions
- Slices and tickets generated by `/to-tickets` are published as GitHub Issues.
- Each issue contains clear acceptance criteria, dependencies ("Blocked by"), and user stories.
