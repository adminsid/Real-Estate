# ADR 016: Serve consumer property searches from a licensed, isolated replica

Status: Production release preparation, October 9, 2026. Public publication remains disabled during verification.

The consumer Worker `prime-property-search` uses its own D1 database and private R2 bucket. It has no MLS credential, Workspace database, CRM, Transactions, or identity binding. Consumers query indexed typed columns and FTS5 rather than the provider API. Stable listing paths remain `/listing/onekey2/{ListingKey}` with server-rendered facts and canonical/share metadata. The consumer site remains primeamericany.com; search.primeamericany.com is the new search destination, with subdomain coverage confirmed by the owner. Placester and the corporate website are unchanged.

The existing Access-protected preview Worker owns the MLS credential and background replication. Signed Access identity is required for every preview route and the configured owner email is additionally required for feed operations. A durable D1 lease serializes replication and media requests. Read the authoritative source cursor only after acquiring the lease. Persist precise provider versions, including sub-millisecond fractions. Atomically apply facts, permission removals, replacement media manifests, and the page cursor. Maintain tombstone versions to prevent stale pages from resurrecting revoked listings.

A visible-only bootstrap is followed by an unfiltered catch-up from the earliest received version before `initial_complete` is set. This captures permission removals during initial traversal. Subsequent deltas omit the viewability filter and follow each source nextLink sequentially. Excluded records still advance the greatest received watermark. A gap longer than six days requires operator reconciliation before resuming; do not infer completeness after the provider's seven-day removal retention.

Signed media URLs remain in invocation memory. Photos are fetched sequentially from the approved MLS GRID host with the required secret header; redirects receive no secret. Validate bounded raster bytes and store in private R2. Photo failures cannot delay facts/removals. Retry URL regeneration only after one hour. Recheck current manifests when downloads finish and before serving files. Optimized variants are supported by the read path; the release initially falls back to validated originals. A production image-transform service and measured mobile photo performance are still required before display review is complete.

Rolling budgets conservatively reserve maximum response bytes before outbound requests, below published request and byte ceilings. Overlapping hourly buckets prevent boundary bursts. Persist request pacing across sync invocations. Credential errors and provider throttling back off. Every consumer read checks complete/fresh source state; after twelve hours without a complete poll, consumer serving fails closed. Unchanged listing modification dates remain distinct from feed freshness.

Indexed queries have deterministic ties, 12/24/48/96-card pages and a 2,500-match display cap. Highlights use already loaded matching results, avoiding an inventory-wide random sort. Public eligibility is checked on every read and responses remain no-store until a generation-safe cache and removal strategy are separately verified.

The first public release covers OneKey-authorized NYC current marketing statuses only. NY State MLS, Prime America exclusives, maps, profile data, and OpenHouse resource replication are separate integrations; no coverage is implied. The release uses published listing emails/phones, with email drafts for questions or preferred showing times. It never represents a draft as a delivered message or a confirmed showing, and does not save demo inquiries into production.

Publication requires three independent checks: release enabled, exact approved origin, and completed display review, plus a healthy complete replica. Approved MLS logos were downloaded from the owner's authenticated documentation page. The designated correction/DMCA contact is info@primeamericany.com. Required disclaimers, attribution, address suppression and eligibility checks are included. The reviewer must verify the current OneKey authorized-field inventory and installation against the executed license before setting display review complete.
