# Consumer search usability session

Status: ready to run with participants; no participant sessions have been conducted. Automated browser checks are recorded separately. Do not report this protocol as completed user research.

Invite older adults and first-time property searchers who consent to a short observation session. Let each person use their usual device, preferred text size and assistive technology. Use fictional inventory or an authorized private preview. Avoid recording personal finances, disability details, housing-assistance documents or confidential messages. Never send a test inquiry to an actual agent.

Read each task aloud without naming the control to use. Observe without coaching; help only after recording where assistance became necessary.

| Task | Prompt | Evidence to record |
| --- | --- | --- |
| Search | Find a two-bedroom property in Queens within an illustrative budget. | Can they see what the phrase means, edit a choice and distinguish a neighborhood from an address? |
| Photos and return | Look through the photos, then return to the same results. | Do they find navigation/Close, use Back successfully, keep their place and understand the photo count? |
| Save | Keep a property for later, reverse that choice, then save and find it again. | Are Save, Saved, Undo and the Saved destination understood without explaining the heart? |
| Map | Explore the map, then return to property cards. | Do they retain the location and budget, understand the map state and find both modes? |
| Contact | Prepare to ask about a viewing without sending a message. | Can they name the recipient, distinguish a draft/request from confirmation, and find a role explanation? |

For each task record device/viewport, text setting, start/end, completion without help, wrong turns, accidental taps, hesitation, requested help and the participant's own words. Ask what they expected after each action. Include keyboard-only and screen-reader sessions, 200% browser zoom and an actual mobile keyboard. Test foldable hardware when available; an ordinary wide window is not equivalent.

Prioritize any misunderstanding about representation, who receives a message, disclosure consent, privacy, a fee or appointment confirmation. Repeated hesitation around navigation, reading and saves is a design finding even if the task eventually succeeds. Fix and retest the affected journey; do not infer universal usability from a small sample or a successful automated test.
