# Consumer search preview: October 12, 2026

The private preview adds Homes / Both / Map layouts, a local NYC borough map, multiple source-reported areas, studio and exact-bedroom searches, bathroom and property-style filters, reported size / parking / tax / monthly-fee filters, rental availability, required and preferred amenities, and comparison of up to four properties. Shared URLs retain filter and layout choices. A listing can open in a separate window for a second monitor.

The map counts all filtered listings independently of card pagination. Coordinates are validated, limited to NYC, and excluded when the source withholds the address. Exact pins are bounded to 2,500 records; selecting a pin or opening comparison rechecks current listing eligibility. Pending searches abort old discovery requests and disable outdated map actions. Unknown facts cannot satisfy required amenity, parking, date, size, or cost filters.

The current OneKey import was inspected read-only and had no coordinates. Borough counts are available; property pins, street maps, commute calculations, neighborhood polygons, and address geocoding are not claimed as delivered. MLS City values are source-reported area names, not verified neighborhood boundaries. No paid map provider or database migration was added. The geometry is a simplified public NYC borough dataset, from https://data.cityofnewyork.us/City-Government/Borough-Boundaries/gthc-hcne; provenance is stored in nyc-boroughs.json.

Verification: 63 Vitest suites / 492 tests passed; Workspace and both search Worker type checks passed; Workspace and search production asset builds passed. Existing Workspace build emits its pre-existing bundle-size warning. Local Chrome checks covered comparison, studio URL restoration, clearing hidden area filters, mobile map / filter sheet, and 320x740, 390x844, 768x1024, 1366x768, 2560x1440, 844x390 viewports without horizontal overflow or console errors. Keyboard controls and reduced-motion styles are included; this is not a claim of formal accessibility certification or physical foldable-device testing.

Independent review found three correctness issues, fixed before deployment: hidden values surviving reset, stale map responses during a new search, and text-valued parking fields passing numeric SQLite comparisons. The latter has a dedicated regression test. Private owner authentication, public release gates, ingestion settings and all unrelated Workspace changes are preserved.
